# Simple Interest Calculator

A simple interest calculator that calculates the simple interest based on the principal amount, rate of interest, and time period.

## Description

This project is a Bash-based simple interest calculator. It accepts the required inputs from the user and calculates the simple interest using the standard formula.

## Formula

**Simple Interest = (Principal × Rate × Time) / 100**

Where:

- **Principal** = Initial amount of money
- **Rate** = Rate of interest
- **Time** = Time period

## Input

The calculator requires:

1. Principal amount
2. Rate of interest
3. Time period

## Output

The calculator displays the calculated simple interest based on the values entered by the user.

## Example

```text
Enter the principal:
10000

Enter the rate of interest:
5

Enter the time period:
